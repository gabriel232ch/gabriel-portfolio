## 已确认的展示原则

## 本次捕获的五个步骤

1. 首页稳定态：健康。签名动画结束后显示正常；三项研究和 Now 顺序符合近期设计。证据：gabriel-audit-01-home.jpg。首次快速捕获时签名尚未出现，不能误判为永久缺失。
2. 首页进入 Chanel：可通过链接键盘激活进入；报告顶部存在主题切换与返回链接重叠。证据：gabriel-audit-02-report.jpg。一次鼠标动作只到达链接所在滚动位置，未完成导航；没有据此认定链接损坏。
3. Chanel 章节目录：键盘激活 Price architecture 后到达正确章节，桌面已有粘性目录。证据：gabriel-audit-03-chart.jpg。目录不是缺失；升级应复用。图表按钮激活尝试工具超时，本次没有验证选择反馈。
4. Olist 详情：内容可读，但只有五条分析步骤、三组指标、限制和一个 GitHub 入口；不足以在站内展示原设计所要求的推理、粒度与验证链。证据：gabriel-audit-04-olist.jpg。新增内容必须来自真实源仓库，不能编造。
5. Smaller companies 详情：保留开放问题语气，但只呈现筛选与五类机制；页面没有可继续检查个案证据的链接。证据：gabriel-audit-05-inquiry.jpg。仓库已有 10 月 2 日新设计及实施计划，应衔接该计划，不另写冲突故事。

## 关键源码证据

- ThemeToggle 使用 fixed top/right 和零 padding，与各详情页自己的 header 不共享排布；两个较短详情页没有主题控制。应统一布局与点击面积。
- 三个详情页返回链接均指向 /#work，不能返回 Olist 或 smaller companies 的对应首页章节。
- BaseLayout 未设置跨页面过渡。签名动画由 CSS 初次加载触发；应区分首次访问与返回首页的阅读意图。
- Chanel 已有滚动进度、目录 aria-current、图表 aria-pressed、数据表折叠与 reduced-motion。升级是在这些基础上完善，不能宣称它们原来不存在。
- 部分入场动画依赖 IntersectionObserver 的比例阈值；实施时需要检验高于视口的节点、深链和返回历史，避免内容长期停留在 pending。

## 推荐设计：保留叙事，统一探索与阅读

### 1. 全站导航

首页保留 WORK / NOW 的轻导航；滚动后出现紧凑导航，提示所在研究，允许直接到达三项研究和 Now。入口以自然标题呈现，不使用 G.xxx、研究分类或系统说明。详情页共享 Gabriel / 返回对应首页章节 / Theme 的排布。移动端重排为两行或菜单，不挤压正文。

### 2. 首页到详情页的连续性

为三个章节设置稳定锚点。详情页返回各自锚点；浏览器 Back 优先还原原位置。支持的浏览器使用短暂标题/页面过渡，保持问题的连续性；其他浏览器正常导航。首次进入保留签名特色，返回阅读时不强制重复长入场。转场不能阻止打开新标签、深链或键盘操作。

### 3. 三种内容节奏

Chanel 沿用深入的逐段证据；完善图表触摸选择、明确可见的选中读数、Escape 清除和完整数据表。Olist 用短的分析链连接增长与履约的矛盾，点击步骤查看真实方法与证据。Smaller companies 按已有新计划呈现问题如何变化，以轻量展开和来源链接连接案例；不把五类机制包装成最终答案。Now 保持日常内容，只把已有真实目的地的条目做成链接。

### 4. 阅读与反馈

复用 Chanel 现有目录和进度；统一活跃章节状态。移动端将长目录改为可展开的章节入口。各研究页提供继续探索其他问题与返回首页的结尾。链接有明确 hover/focus/pressed 状态，触摸操作不依赖 hover。新增 Quiet 控制用于减少签名和数据编排，仍保留所有内容；系统 reduced-motion 自动优先生效。

### 5. 实施验收

生产现状只有桌面浅色截图，本次没有完成移动端、深色、屏幕阅读器或完整图表行为验证。
实施验收覆盖 390px 与 1440px、浅色/深色、键盘、触摸、reduced-motion、无脚本内容可见性、深链、往返导航、长内容入场和主题持久化。运行仓库 check/lint/unit/build 与相关 E2E；截图回归逐处审核，不盲目更新基线。
测试关注行为：位置还原、选择反馈、导航可达、聚焦回归和证据链接。不能仅镜像实现。
