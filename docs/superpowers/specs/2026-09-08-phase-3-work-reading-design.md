## Routes and composition

- `/work/`: editorial ruled list, project title, discipline, summary, ongoing status; no cards or decorative permanent IDs.
- `/work/<slug>/`: Open (title and question), conclusion, evidence, Markdown analysis and limits, sources, Continue reading.
- `/work/luxury-handbag-pricing-architecture/reading/`: identical Markdown, claims and precise data, in a quiet single reading column with print styles. Mode links are native anchors.

Desktop case pages use marginal contents and an offset reading column. Mobile uses a linear sequence with wrapping native section links. The luxury evidence scene separates France/EUR and US/USD. Charts show sampled minimum, quartiles, median and maximum on zero-based per-market scales, with exact equivalent tables. No cross-currency ranking or fabricated causal interpretation. Native details expose tables without JavaScript; Reading Mode opens them by default.
