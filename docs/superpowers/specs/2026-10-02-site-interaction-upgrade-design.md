# Gabriel Portfolio — Site Interaction Upgrade v1

日期：2026-10-02

## 1. 目标与依据

让读者能够顺畅地认识 Gabriel、跟随问题进入研究、检查证据，再返回原来的阅读位置。首页继续表现思考和生长；交互提供方向感、连续性与真实探索。

用户已确认的范围：统一导航、首页与详情往返、保留三种研究节奏、可探索的证据、移动端阅读与减少动效模式。

依据按近期决定优先：

- `2026-09-17-homepage-personal-digital-home-redesign-design.md`。
- `2026-09-17-chanel-homepage-cinematic-chapter-design.md`。
- `2026-09-18-typography-scale-v1-design.md`。
- `2026-10-02-smaller-companies-inquiry-public-archive-and-site-design.md` 及其网站/归档实施计划。
- `docs/audit-2026-10-02/interaction-review.md` 与本次生产截图。

原始 Living Index 设想不覆盖后续首页决定。本次不加入完整 Index、Archive、CMS、社交平台集成或新内容路由，不重选框架、字体或颜色体系。

## 2. 保留与修正

保留首页顺序：Hero → Chanel → Olist → Smaller companies → Now → Closing。保留手写签名、规范中的公开叙事、项目差异、开放问题与隐私边界。

修正：详情页顶栏布局、三项研究的准确返回目的地、导航状态、跨页连续性、图表选择反馈、短详情页的阅读结构和证据入口。

首页不增加项目编号或研究分类。Chanel 详情页去掉无导航作用的 `WORK / RESEARCH`、`RESEARCH / PRICING` 与装饰 folio；保留数据期间、币种、来源、必要图号和正文中的引用对应关系。目录序号可以用于辨认章节，不能把设计分类作为研究结论。

正文与标题继续使用已批准的全站语义字号。移动端正文遵循至少 20px 的既有要求；不能通过缩字解决拥挤。详情标题不能大于首页项目标题。

## 3. 全站导航

### 首页

首屏继续只有 WORK、NOW 和主题控制，不把 Hero 变成目录。

Hero 离开视口后显示紧凑的粘性导航：Gabriel Chen 返回首页顶部；`Explore` 打开研究入口；`Now` 到日常区域；主题与 Quiet 控制在同一布局中。显示当前章节的短名称：Chanel、Olist、Smaller companies 或 Now。短名称只承担定位功能；展开入口使用完整自然标题。

Explore 使用原生 disclosure 语义，包含三项研究的首页锚点与 Now。它不是全屏模态，不锁定滚动；关闭时不保留隐藏可聚焦项。Escape 关闭并将焦点还给触发器；选择入口后关闭，并使目标标题可聚焦。点击之外关闭不得取消真实链接行为。

移动端采用两行顶栏：身份/主题/Quiet 与 Explore/当前章节。标题截断只影响导航显示，完整名称仍可从展开列表读取。控件至少 44×44 CSS px，条目可以自然换行。顶栏不可覆盖正文或遮挡目标标题。

### 详情页

三个现有详情页共享顶栏排布：Gabriel Chen、`Back to home`、Theme、Quiet。主题按钮由布局放置，不再独立 fixed 占用右上角。桌面可单行，移动端可两行。

顶栏在研究阅读过程中保持可达。首页与详情均包含可见于键盘聚焦时的 skip link。主题设置沿用现有持久化行为，初始化与访问存储失败时仍可阅读与操作。

## 4. 稳定目的地与往返

新建首页章节锚点 `#chanel`、`#olist`、`#smaller-companies`；现有 `#work` 和 `#about` 保持兼容。Now 导航仍可指向现有 Now 区域，不在本次移除旧锚点。

详情页 Back to home 分别链接 `/#chanel`、`/#olist`、`/#smaller-companies`，无脚本时同样有效。

浏览器 Back/Forward 优先使用浏览器原生滚动还原。不能把原生历史返回强制改为章节顶端。显式 Back to home 链接定位对应章节标题。直接打开详情页时，也有正确的首页目的地。

链接保持标准语义：修饰键、新标签、中键、复制地址和深链均可用。不采用依赖 `history.back()` 的假返回链接。

首次正常进入首页保留签名特色；从详情返回和带章节 hash 打开首页时不重复长签名编排。Quiet 与系统 reduced-motion 下直接呈现完整签名。浏览器历史缓存还原时不重置已显示内容。

## 5. 页面连续性与动效

支持的浏览器可使用原生跨文档 View Transition，不以客户端路由重写现有 Astro 架构。

只有适合对应的标题/页面元素做短转场；Chanel 首页问题标题与详情分析标题文本不同，不强行把两段不同文本拉伸 morph。可使用轻淡入衔接。禁止通过 transform 缩放正文或让文字模糊。

操作反馈约 120–220ms，页面衔接约 180–280ms。这是新交互的时长范围；不机械覆盖原有叙事入场曲线。避免等待动画结束才允许点击、关闭或导航。

首页叙事节点按原有不同节奏入场一次。内容默认可见，脚本成功初始化后才启用增强；观察阈值不能导致高于视口的内容永久隐藏。深链、快速滚动、历史返回、resize 后所有内容可达。

运行中改变系统 reduced-motion 或 Quiet 时即时取消非必要编排并显示完整内容；不能只在首次加载读取一次偏好。

### Quiet

Quiet 是独立的动效偏好，不改变颜色主题。控件使用按钮与 aria-pressed，文字状态可辨认。保存用户选择；存储不可用时本次页面仍能生效。

有效 Quiet = 系统 reduced-motion 或用户主动开启。系统要求减少动效时不能通过按钮强制重启动效；界面说明使用系统偏好。Quiet 停止签名绘制、滚动入场、图表组装和跨页位移动画；图表选择、导航和数据仍完整工作。

## 6. Chanel：可检查的证据

复用现有十节目录、阅读进度、图表和数据表，不重做已有能力。

桌面保留侧栏与活跃章节状态；移动端将目录放入可展开的 `On this page`，显示当前章节。选择章节后关闭目录并定位/聚焦对应标题。锚点 offset 包含顶栏与安全区。

进度按研究正文起点与终点计算，首页/报告开屏留白不作为主要阅读进度。进度更新不向屏幕阅读器持续播报，结束时达到完成状态。

图表鼠标 hover 提供预览，点击/触摸或键盘激活锁定一个数据点；再次激活同点清除，Escape 清除。预览不能覆盖锁定选择。选中态与 aria-pressed 一致，图表下方显示包含系列、市场/年份、数值/单位的可见读数。仅主动选择更新 polite 状态信息。

不用颜色作为唯一选中提示。触摸不依赖 hover；小数据点具有足够点击区且不阻挡相邻项。清除按钮有明确文字，不只依赖点击图表空白。

完整数据表使用原生 details/summary，汇总标题可读。溢出区域在窄屏可横向滚动，并提供可见提示和键盘访问；不通过整页横向溢出容纳表格。

不变更真实数据、单位、采样边界、来源期间或因果解释。必要图号与正文引用继续一致。

## 7. Olist：短而有推理的阅读

首页仍是紧凑的能力成长叙事。图示不伪装成可点击控件，也不为了交互把完整分析塞到首页。

详情继续以真实问题引入，重组现有五条分析步骤为可展开的分析链。每项包含：问什么、为什么这样检查、数据粒度/口径、已验证发现、直接证据入口。问题与关键发现默认可见；SQL 或补充方法可以展开，不隐藏结论才能读懂主线。

所有新增方法、数值与证据链接必须读取现有 `olist-marketplace-analytics` 源仓库核验。不能从展示指标推演未经验证的分析。来源不可访问时保留现有已验证内容，明确记录缺口，不填充占位故事或假链接。

增长与履约的矛盾作为重点关系展示；不堆叠通用 dashboard 卡片。增加短目录与正确来源入口，结尾继续到其他研究或返回对应首页位置。

## 8. Smaller companies：衔接已有演进计划

今天的研究演进设计仍是内容权威。本升级为其提供共享导航、阅读目录、轻量展开、来源入口、Quiet 与往返行为。

保留公开标题与现有路由。详情呈现问题如何变化、哪些证据推动改变和哪里仍不确定。现有 benchmark 作为其中一次研究，不再独占整页。

不复制私有访谈、员工姓名、原始评估记录或内部网页。公司名称作为公开外部案例可以出现，但不能暴露雇主内部材料。真实证据链接需以 companion archive 已发布的文件为依据。

执行前检查 10 月 2 日 companion 工作是否已更新同一路由：若已完成，在新内容上加入交互；若未完成，复用其内容计划与来源约束，不另创第二套叙事。未存在的归档不能作为可点入口。

## 9. Now 与结尾

Now 保持 Learning / Working on / Playing / Thinking about 的日常内容；有真实站内目的地的条目才成为链接，其他项保持纯文字。没有按钮外观的死控件。

结尾保留 `I’ll keep adding things here as I go.` 与已有真实个人链接。详情页加入轻量 `Other questions` 导航，指向另外两项真实研究，不重复大项目卡片，不增加求职 CTA。

## 10. 组件与状态边界

保留 BaseLayout 作为主题、motion 偏好和增强入口。共享导航、研究目录、研究结尾和图表选择逻辑各自独立；内容数据与交互状态分开。

首页通过稳定章节注册表维护标题、锚点、详情路径和导航短名称。注册表不是另建 Living Index 产品，不在 UI 暴露内部 ID。

滚动定位与目录状态由文档结构派生，不要求服务端、账号或分析埋点。展开状态留在当前页面；主题/Quiet 跨页持久化。导航或增强失败时使用真实链接与原生 disclosure。

## 11. 验证与完成标准

测试矩阵至少包含 390px 手机与 1440px 桌面，浅色/深色，普通动效/reduced-motion/Quiet，鼠标/键盘/触摸。

- 四个页面的导航、主题与 Quiet 不重叠，不产生整页横向溢出。
- 首页 → 每个详情 → Back to home 准确返回对应章节。
- 浏览器 Back 还原阅读位置；直接详情、直接章节 hash 与新标签正常工作。
- 键盘可以打开/关闭导航与目录，选择锚点、图表数据和数据表；焦点可见且返回合理。
- 图表选择读数、aria-pressed 与实际数据一致，Escape/清除有效。
- 长内容、快速滚动、resize、历史还原不会使正文或图表永久不可见。
- 无脚本仍可读正文、访问来源、导航与展开原生数据表。
- 系统动效偏好运行中变化能够生效。
- 研究页新增内容的来源、口径与隐私逐项核验；没有假链接或未验证结论。
- 运行仓库 check、lint、unit、build 和相关 E2E；所有相关失败解决后才报告通过。
- 视觉 QA 逐个状态查看，截图基线只对已审核的有意变化更新。

本次审计证据仅覆盖桌面浅色生产页面；尚未验证手机、深色、完整图表行为或屏幕阅读器，不能将审计当作以上验收已完成。

实现完成后提供可审核预览、变更摘要、验证结果和剩余来源缺口；生产发布沿用现有 GitHub/Cloudflare 项目与审核流程。本规格的通过不代表部署已经完成。

## 12. 参考与采纳方式

- Emil Kowalski, You Don't Need Animations: https://emilkowal.ski/ui/you-dont-need-animations 。采用有目的的快速反馈，避免频繁操作等待。
- Emil Kowalski, Great Animations: https://emilkowal.ski/ui/great-animations 。采用可中断、性能友好及 reduced-motion 的增强。
- Linear, A calmer interface for a product in motion: https://linear.app/now/behind-the-latest-design-refresh 。导航提供结构但保持视觉安静。
- Rauno Freiberg, Invisible Details of Interaction Design: https://rauno.me/craft/interaction-design 。用于交互细节研究，不声称本次已逐项试用参考网站。

这些参考提供交互原则；具体布局服从 Gabriel 已批准的个人数字空间与阅读规格。
