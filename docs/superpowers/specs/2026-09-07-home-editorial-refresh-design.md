# Home Editorial Refresh — 设计决策

日期：2026-09-07。用途：与同日执行方案一起交给 GPT‑5.6 Luna / xhigh。

## 目标与授权背景

用户认可本次首页评估，要求一份完整执行方案。下一位执行者收到“按方案执行”的指令后，按本设计完成整页本地改版；当前任务仅产出方案。

目标：保留编辑式审美，让访问者快速认识作者、理解三个项目的发现，并获得真实的阅读去向。方向为“有作者的研究手记”。

现状证据：`docs/audit-2026-09-07/review.md` 及同目录截图。截图用于理解现状，不是要复制的目标。手机仅检查过首屏，暗色与完整移动端仍需执行者验证。

## 本轮确定的设计

- 保留 Astro 静态页面、现有字体资源、浅深主题、4/6/12 栅格、三个项目顺序。
- 首页语言保持英文。文案采用执行方案给定版本；项目发现仅压缩现有证据。
- 导航显示 WORK / NOW。继续保留 `#work`、`#about`、`#index` 旧锚点，后两者分别对应近况和页尾。移除可见的 INDEX 自指链接。
- 首屏：姓名、具体个人介绍、两个无日期的项目阅读链接。删除内部建设里程碑列表，不制造“最近发表”的日期或事件。
- 作品：短标题、一句发现、默认可见的关键证据、原生展开的完整研究笔记。全部研究问题、完整结论、证据和必要边界仍保留。
- Luxury 展示两市场原有价格图，默认美国展开、法国折叠；不更改算法或数据。
- Olist 同时展示已有 GMV 与准时交付两个指标，六个 Fix 市场保持可展开；不声称修复方案已经带来实际收益。
- Competitive 默认展示一句核心发现和五个机制名称，第一项说明展开；不加入未经证实的公司案例或胜率。
- Now 保留实际主线和两条支线，加入源于原有网站定位的简短作者说明；照片和 archive 继续为 null，无空位，无虚构个人经历。
- 页尾提供返回作品和两个已有公开项目来源，不建立新的 About、Work 详情、Index 或联系页面。
- 字号、间距、布局变化限定在 Home；全局 tokens、lab 和主题机制原则上不变。
- 不引入 Figma、图片生成、新框架、动画库、CMS、图谱或新依赖。

## 与历史文档的关系

本轮明确更新 Phase 2 的首屏层级、首页文字角色、QUESTION/OUTCOME 首屏展示方式、导航可见名称、两条 movement 约束与页尾构成。历史“frozen”描述记录当时接受的版本，不阻止本轮已明确的修改。原始研究真实性、公开/私有边界、no-JS、reduced-motion 和主题契约继续有效。

历史验收记录不得改写为本轮通过；本轮另建 review 文档。样板先行是内部实现顺序，收到执行授权后无需每完成一个区块就等用户许可；最终视觉满意度由用户判断。

## 验收

整页的三个作品、近况与页尾全部完成；桌面与手机、浅色与深色都实际检查；内容默认可读；展开、键盘、锚点与主题工作；重要文本不再使用约 8–10px 字号；不存在横向溢出；不产生虚构内容或公开私有研究的新动作。完整命令与具体测试见执行方案。
